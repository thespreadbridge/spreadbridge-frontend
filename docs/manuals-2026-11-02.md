# 설치 매뉴얼 (2026-11-02)

## 자료와 공개 경로

- 원본: Google Drive `메뉴얼 (API 신청, 등록)` 폴더, v1.0 PDF·PPTX 각 3개.
- 폴더: https://drive.google.com/drive/folders/1_3-6qzAF8lJ2yWKLJmQe7qkcbaaexbFf
- 원본 Drive 파일은 보존하고 공개 파일을 v1.1로 수정했다.
- `/manuals/`: 로그인 없이 설치·업비트 API·한국투자증권 API 가이드 열람.
- `public/manuals/v1.1/{install,upbit,kis}/`: 각 PDF·PPTX와 PDF에서 렌더한 4쪽 WebP.
- `src/content/manuals.json`: 문서 메타데이터와 페이지별 접근성 텍스트.
- 상단 주요 메뉴 마지막, 지원 푸터, 다운로드·시작 가이드에서 연결한다.

## 문서 보완

기존 디자인과 화면 이미지를 유지하고 준비사항 임시 문구, 한투 마지막 쪽의 업비트 제목, 하단 페이지 번호와 메시지 표기를 수정했다. Windows·Mac 설치와 연결 결과 확인 문구를 보완했다. 화면 기준일은 원본의 2026.11.01을 유지한다. API 권한은 업비트 공식 자료 https://docs.upbit.com/kr/docs/api-setup 와 대조했다. 발급·거래는 수행하지 않았다.

PPTX는 Artifact Tool로 수정하고 구조·레이아웃·재가져오기 검사를 통과했다. PDF는 같은 PPTX에서 한글 글꼴을 명시해 변환했고 최종 12쪽을 각각 렌더해 확인했다. 내장 이미지에도 원본의 마스킹이 적용되어 있음을 확인했다.

## 검증

- TypeScript, Next.js production build, 기존 Vitest 19개 파일·163개 테스트 통과.
- 로컬 Chrome: 가이드 열기, 이전·다음, 첫/마지막 버튼 제한, 텍스트 펼치기, Esc 닫기·포커스 복귀 확인.
- Chrome에서 PDF·PPTX 다운로드 후 공개 원본과 바이트 일치 확인.
- 6개 파일과 12개 이미지 HTTP 응답 및 앱 번들 이미지 일치 확인.
- 앱의 연결 화면은 거래소에 연결하지 않는 기존 fixture로 검증했다. 실제 로그인/API·주문 검증과 구분한다.

운영 반영은 기존 Git main push → Vercel 자동 배포 흐름을 사용한다. 로컬 검증 결과만으로 운영 배포 완료를 판단하지 않는다.
